# Mago Vituco · Tu elección

Truco de magia interactivo (React + Vite + Tailwind). Sitio 100 % estático, sin backend.

## Imágenes (recomendado)
Guarda las 3 imágenes en `public/images/` con estos nombres:

- `logo.png`
- `grid.jpeg`
- `final.jpeg`

Si no están, la web intenta cargarlas desde el CDN de Base44, que puede dejar de funcionar.

## Probar en local
```bash
npm install
npm run dev
```

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta (rama `main`).
2. En el repositorio: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Cada `git push` a `main` publica la web automáticamente en
   `https://TU_USUARIO.github.io/NOMBRE_REPO/`.
